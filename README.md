A program that writes one line to `/output/entry.txt` (124 characters, inside the 200-character cap): the excuse a hardware wallet gives for refusing to sign a transaction at 3 AM — it only takes orders from daytime you, because 3 a.m. you once swapped the rent for a coin called MOON and blamed the wallet's buttons.

## Run it

```sh
python3 main.py
```
